# Music Player 🎵

A keyboard-controlled music player built with Pygame.

## Features
- Play / Stop / Pause music
- Next / Previous track
- Auto playlist support
- Progress display

## Controls
- P → Play
- S → Stop
- SPACE → Pause/Resume
- N → Next track
- B → Previous track
- Q → Quit

## How to run
```bash
python main.py
